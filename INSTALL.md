# Install Voucherboard

Voucherboard comes as a browser extension and as an app for iPhone, iPad and Android. Each one works with Lewisham's
visitor parking permit site, `parkingpermits.lewisham.gov.uk`, in your own signed-in session.

| Where | How | Status |

Once it's installed, the [guide](voucherboard/guide/README.md) shows how to use it.

## Chrome or Brave

1. Open [Voucherboard on the Chrome Web Store](https://chromewebstore.google.com/detail/voucherboard-beta/cldhejnblckejbeebjidikhebdfnncak).
2. Choose **Add to Chrome**, then **Add extension**.
3. Open `https://parkingpermits.lewisham.gov.uk` and sign in as you normally would.
4. Choose the **Voucherboard Beta** button in the bottom-right corner.

### Load it unpacked (developers)

1. Download `voucherboard-<version>-unpacked.zip` from the [latest GitHub release](https://github.com/maubergine/voucherboard/releases/latest), and unzip it.
2. Open `chrome://extensions`, and turn on **Developer mode**.
3. Choose **Load unpacked**, and select the unzipped `voucherboard` folder.
4. Open `https://parkingpermits.lewisham.gov.uk` and sign in.

## Microsoft Edge

Voucherboard isn't on Microsoft's own add-ons store. Edge installs it from the Chrome Web Store instead.

1. In Edge, open [Voucherboard on the Chrome Web Store](https://chromewebstore.google.com/detail/voucherboard-beta/cldhejnblckejbeebjidikhebdfnncak).
2. In the banner at the top of the page, choose **Allow extensions from other stores**, then **Allow**.
3. Choose **Get** (it may say **Add to Chrome**), then **Add extension**.
4. Open `https://parkingpermits.lewisham.gov.uk` and sign in.
5. If the Voucherboard button doesn't appear, open **Extensions** (the puzzle piece) in the toolbar, then **Manage
   extensions**. Under Voucherboard, choose **Details**, and check that **Site access** allows the council's site.
   Then reload the page.

## Firefox

Coming soon on [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/voucherboard/).

1. Open Voucherboard on Firefox Add-ons, and choose **Add to Firefox**, then **Add**.
2. Open `https://parkingpermits.lewisham.gov.uk` and sign in.
3. Firefox asks before an extension can read a site. Open **Extensions** (the puzzle piece) in the toolbar, and choose
   **Always allow on parkingpermits.lewisham.gov.uk** under Voucherboard. Then reload the page.

## Safari on a Mac

Coming soon, as a signed download from the [latest GitHub release](https://github.com/maubergine/voucherboard/releases/latest).

1. From the release, download `Voucherboard-Safari-<version>.zip` and open it.
2. Move **Voucherboard** to your Applications folder, and open it.
3. Choose **Open Safari extension settings**, and tick **Voucherboard**.
4. Select Voucherboard, choose **Edit Websites**, and set `parkingpermits.lewisham.gov.uk` to **Allow**. Or, on the
   council's site, choose the Voucherboard icon next to the address bar, then **Always Allow on This Website**.
5. Open `https://parkingpermits.lewisham.gov.uk` and sign in. The Voucherboard button is at the bottom right.

You can quit the app once it's set up. To update, replace it with the new version and open it once. Deleting the app
removes the extension.
