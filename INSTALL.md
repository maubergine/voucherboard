# Install Voucherboard

Voucherboard comes as a browser extension and as an app for iPhone, iPad and Android. Each one works with Lewisham's
visitor parking permit site, `parkingpermits.lewisham.gov.uk`, in your own signed-in session.

| Where | How | Status |
| --- | --- | --- |
| [Chrome or Brave](voucherboard/guide/README.md#chrome-or-brave) | Chrome Web Store | Available |
| [Microsoft Edge](voucherboard/guide/README.md#microsoft-edge) | Chrome Web Store | Available |
| [Firefox](voucherboard/guide/README.md#firefox) | Firefox Add-ons | Coming soon |
| [Safari on a Mac](voucherboard/guide/README.md#safari-on-a-mac) | Download from GitHub (Voucherboard for Safari) | Coming soon |
| [iPhone and iPad](#iphone-and-ipad) | App Store | Coming soon |
| [Android](#android) | Google Play | Coming soon |

## Browser extension

The extension works the same in every browser. The [guide's Install section](voucherboard/guide/README.md#install)
has the steps for each one, and the rest of the [guide](voucherboard/guide/README.md) shows how to use it.

## iPhone and iPad

Coming soon on the App Store. The app works with the council's site for you, so you don't need a browser extension.
Open it, sign in to your council account, and accept the terms.

## Android

Coming soon on Google Play. It works the same way as the iPhone app.
